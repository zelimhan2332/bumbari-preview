# Печать лекал — обязательное требование владельца

Владелец прямо добавил: «распечатка лекал тоже нужна».
Пользователь должен получить физические лекала с телефона, а не только
картинку на экране.

## Два режима

### A4 — обычный принтер

- Разбивка на страницы без изменения физического масштаба.
- Номера строк/столбцов, схема сборки и метки совмещения.
- Настраиваемые поля принтера; учитывать реальную печатную область.
- Нахлёст для совмещения листов. Предложение по умолчанию — 10 мм,
  с возможностью изменить после проверки удобства склейки.
- Линии обрезки полей, понятные инструкции «как собрать».
- Перед экспортом показывать число листов.
- Не добавлять пустые страницы из-за округления координат.

### Цельный лист / плоттер

- PDF в натуральную величину на выбранном формате/ширине рулона.
- Размер страницы соответствует комплекту или выбранной раскладке.
- Детали не выходят за границу листа и не обрезаются.

## На каждом комплекте

- Изделие, размер/идентификатор проекта, дата и версия построения.
- Названия деталей, количество, долевая и контрольные метки.
- Ясно указано, включены ли припуски и какой они величины.
- Контрольный квадрат 100 × 100 мм и линейка для проверки масштаба.
- Понятное напоминание: «Печать 100% / фактический размер».

## На Android

- Действия «Сохранить PDF», «Поделиться» и «Распечатать».
- Для печати использовать штатный Android Print Framework / доступную службу принтера.
- Если совместимая служба/принтер не найдены, предложить сохранить PDF
  для печати с другого устройства, не выдавать это за успешную печать.
- Поддержку конкретного Wi-Fi/Bluetooth/USB-принтера проверять на реальном устройстве.

## Проверки

- Для PDF использовать точное преобразование: 1 мм = 72 / 25.4 пункта.
- Визуально отрендерить итоговый PDF и проверить метки, подписи и края.
- Программно проверить квадрат 100 мм и координаты известных отрезков.
- Собрать хотя бы один A4-комплект на бумаге и измерить квадрат линейкой.
- Не смешивать проверку цифровой геометрии с погрешностями конкретного принтера.
