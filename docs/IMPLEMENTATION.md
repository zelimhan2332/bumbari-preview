# План реализации для Claude

## Этап 1. Источники и расчётная модель

- Проверить книги из `source-inventory.json`; выбрать конкретные редакции основ.
- Составить карту покрытия категорий и список недостающих источников.
- Оцифровать последовательность построения: мерки → вычисляемые величины →
  точки → линии/кривые → вытачки → детали → припуски.
- Хранить идентификатор источника и диапазон страниц около алгоритма.
- Ввести контрольные примеры из книг и граничные наборы мерок.

## Этап 2. Общее ядро

- Чистые функции расчёта, независимые от интерфейса Android.
- Миллиметры, явные системы координат и преобразования.
- Линии, дуги/кривые, пересечения, длины, разрезание и соединение контуров.
- Припуски отдельно от исходной линии шва, обработка острых углов и вытачек.
- Проверки замкнутости, пересечений и согласования срезов с учётом предусмотренной посадки.
- Формат проекта с версией схемы и алгоритма; проверка входных данных.

## Этап 3. Понятный интерфейс и первый полный цикл

Создать общий каталог и мастер из четырёх шагов. Первое полностью работающее
построение рекомендуемо взять из прямой юбки: это позволяет проверить весь
цикл, печать, вытачки и припуски на обозримом алгоритме.

Название других изделий в каталоге не означает готовность: незавершённые
модули не должны генерировать фиктивные детали.

## Этап 4. Семейства конструкций

1. Женские основы: юбка, брюки, лиф/платье, рукав.
2. Блузки/платья и моделирование по соответствующим источникам.
3. Мужские основы: брюки, рубашка, жилет/пиджак, рукава.
4. Жакеты, пальто и куртки; прибавки и пакеты материалов.
5. Воротники, манжеты, пояса, карманы, подкладка и дополнительные детали.
6. Бельё, свадебная/вечерняя одежда, кожа — отдельные правила по книгам.
7. Детские конструкции — после получения и проверки подходящей методики.

Каждый этап заканчивается работающим модулем и проверками, а не только экраном каталога.

## Этап 5. Экспорт и APK

- Векторный PDF с правильными физическими размерами.
- Плиточная A4-печать, поля принтера, нахлёст и метки совмещения.
- Пример сохранённого проекта, восстановление и повторяемость расчёта.
- APK с собственным package ID и отдельным ключом подписи вне Git.
- Установка и проверка на Xiaomi 13 Ultra.
- Документированный способ собрать проект заново.

## Предложение по архитектуре

`measurement schema` → `construction modules` → `geometry` → `pattern pieces`
→ `viewer` / `PDF exporter` → Android-оболочка.

Стек выбрать после проверки библиотек и требований печати. Возможен общий
TypeScript-движок с локальным интерфейсом внутри WebView, но открывать браузер
вместо установленного приложения не следует. Для расчётов не нужен LLM или сервер.
