# Юбка из четырёх клиньев

Комплект `FourGoreKit` строит четыре одинаковых симметричных клина и пояс по
полным меркам талии, бёдер, высоте бёдер и длине. В долях одного клина
ширина по талии равна `(От + прибавка по талии) / 4`, а по бёдрам —
`(Об + прибавка по бёдрам) / 4`. Между уровнями ширина плавно меняется;
ниже бёдер задаётся расширение каждого клина по обеим боковым сторонам.

## Источник и границы

«Ателье — 2001», PDF 5–8: основа прямой юбки. PDF 8 (печатная стр. 9)
показывает разрезание переднего и заднего полотнищ до линии бёдер,
расширение книзу, закрытие вытачек и перенос остатка. Для переда и спинки
сохраняется одинаковая общая величина расширения. Это описание служит
методической опорой. Равное распределение фигуры на четыре одинаковых детали
и плавная цифровая кривая — инженерное преобразование для симметричной
модели, а не отдельная готовая четырёхклинная формула из книги.

Приложение пока строит геометрическую основу и не моделирует особенности
живота, ягодиц, асимметрию, вытачки, подкладку или поведение материала.
Перед раскроем основной ткани нужны макет и примерка; посадка физически не
проверена.

## Детали и печать

- A: клин, выкроить 4 раза; припуски на талию и боковые швы включены.
- B: прямой пояс, 1 деталь плюс прокладка; длина совпадает с линией талии,
  добавлен 3 см выступ для застёжки.
- Один боковой шов используется для молнии.
- PDF A4 печатается плитками с нахлёстом 10 мм; A0 — для плоттера.
- В PDF есть долевая и контрольный квадрат 100 × 100 мм. Печатать в масштабе
  100%, отключив вписывание в страницу.

Точная посадка, стабильность талии и отвисание низа требуют физического
макета. Встроенная проверка геометрии не заменяет их.
