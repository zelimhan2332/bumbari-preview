# Первый чертёж прямой юбки

Источник: «Основные конструкции» (сборник 2005), PDF-страницы 3–5,
рисунки 1–4. Сверено с изображениями PDF, а не только с OCR.

`preview/skirt-drawing.js` рисует переднее и заднее полотнища, уровни талии,
бёдер и низа в координатах, рассчитанных из сантиметров. Общая ширина на
линии бёдер равна `Об/2 + прибавка 1–2 см`; линия бока делит её пополам.
Высота бёдер и длина юбки берутся из введённых мерок.

Для двух полных числовых примеров книги (От 76 или 72, Об 100, Вб 20,8,
длина 61,5 см, прибавка 1 см) показаны боковые линии и вытачки. Проверенные
суммы: 12 = 7 + 2 + 3 см и 14 = 7 + 2 + 3 + 2 см. Положение и длина
вытачек взяты из указанных в книге диапазонов и служат визуальной схемой;
их индивидуальная форма и баланс не проверены. Для иных мерок показана только
сетка, без выдуманного распределения вытачек.

Это ещё не лекало для раскроя: не уточнена талия при закрытых вытачках,
не согласованы срезы, не добавлены припуски и печать 1:1. Расчётный SVG
масштабируется для экрана и физический масштаб не сохраняет.
