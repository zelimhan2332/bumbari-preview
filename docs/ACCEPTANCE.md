# Приёмка результата

## Математика и методика

- Для каждого изделия названы источник, редакция и страницы.
- Все обязательные мерки определены и отделены от расчётных.
- Контрольный пример книги воспроизводится с проверкой ключевых величин.
- Формулы после OCR проверены по оригинальной странице, включая дроби и знаки.
- Прибавки, вытачки и припуски не смешиваются.
- Отрицательные, нулевые и противоречивые мерки не создают молча испорченный результат.
- Проверены несколько размеров и нетипичных пропорций, область применимости указана.

## Геометрия

- Детали замкнуты, нет неожиданных самопересечений и разрывов.
- Долевая, названия деталей, контрольные метки и количество деталей присутствуют.
- Парные срезы проверены по длине с учётом именно предусмотренной методикой посадки.
- Припуски создаются корректно на кривых, углах и возле вытачек.
- Изменение одной мерки воспроизводимо перестраивает результат.

## Экспорт

- Геометрический квадрат 100 × 100 мм имеет правильный размер в PDF.
- Векторное качество сохраняется при увеличении.
- Плиточная A4-печать не обрезает детали и позволяет совместить листы.
- Перед печатью ясно указано: масштаб 100%, не «вписать в страницу».
- Проверено повторное открытие сохранённого проекта.

## Работа на телефоне

- APK устанавливается рядом с Уммой и не заменяет её.
- Крупные органы управления; экран помещается на телефоне.
- Ввод точкой/запятой работает; введённые мерки не пропадают при переходах.
- Тестовый пользователь проходит четыре шага без объяснений разработчика.
- Расчёт и просмотр работают без интернета.

## Честный статус

- Готовые и экспериментальные модули различимы.
- Физическая примерка не заявляется выполненной по результатам программного теста.
- Контроль посадки на пробном изделии проводится отдельно с портным.
- В README перечислены реально поддерживаемые изделия и реальные ограничения.
