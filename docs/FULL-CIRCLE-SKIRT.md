# Юбка-солнце — полотнище180°

Выбор владельца: следующая модель «Юбка180°» из каталога, тем же порядком,
что полусолнце. Полное изделие360°, перед и спинка — по180°, два боковых шва,
молния в одном боковом шве. Один шаблон полотнища выкроить два раза без сгиба.
Это позволяет получить оба боковых припуска без наложения ткани у разреза
цельного замкнутого круга. Подкладка не включена.

## Источник

Визуально прочитаны b07 «Свадебные и вечерние платья», томI, PDF170–172.
PDF170, рис.2: юбка-солнце, четверть ширины, выкроить4 раза; радиус
От/6−1см. PDF172, рис.6: верхняя юбка дополнительно раздвигается у низа
на12–15см в каждом разрезе; нижняя остаётся без этого расширения.
Это двухслойный свадебный наряд с корсажем, не универсальная отдельная юбка.
PDF171 содержит продолжение болеро и не даёт иного расчёта юбки.

Выбранная отдельная модель — геометрическое солнце без раздвижки/сборки:
r=(От+прибавка)/(2π). Поправка−1см из свадебного примера не применена.
Это явное инженерное решение ради точного совпадения пояса и талиевого шва,
а не заявление о буквальном воспроизведении модели книги. Например при От72:
книжный r=11см даёт окружность69,115см; наша модель с прибавкой1см даёт
r=11,6183108457см, обхват73см и дугу каждого полотнища36,5см.

Пояс по b10 PDF9, рис.9; общий принцип припусков/знаков по b10 PDF16, рис.29.
Параметры обработки и прибавок индивидуальные, по умолчанию как у полусолнца.

## Геометрия и полный комплект

Общий движок `half-circle-kit.js`, функция buildCircle: полный угол360°,
два полотнища180°. На одном шаблоне положительная полуплоскость x≥0,
две линии боковых швов x=0 при y≥r и y≤−r. Оба припуска x=−s,
талия r−s, низ R+h, пересечения аналитические. Сгиба на шаблоне нет.
Четвертные метки на середине каждого полотнища и поясе, конец молнии,
долевая по середине переда/спинки, перпендикулярно линии боковых швов.

При раскладке в один слой долевая каждого полотнища направлена по длине ткани.
Нужна полезная ширина2(R+h); два полотнища последовательно занимают
длину2(R+h+s). Затем отдельная полоса пояса, долевая вдоль его длины,
плюс4см промежутков. Расход консервативный, без усадки/раппорта/отвисания.

Модель skirt180: собственные мерки/настройки fullCircle/заметки/localStorage,
JSON, шаги мерки→лекала→PDF. PDF A4/A0 использует тот же комплект, содержит
квадрат100мм, R/C и нахлёст10мм. Печатать100%. Перед основной тканью — макет,
затем отвисание и выравнивание низа. Физическая печать и посадка не подтверждены.
