# Обновление Android-приложения без кабеля

## Как работает

На главном экране нажать «Проверить обновления». Приложение получает `update.json`
из последнего GitHub Release, сравнивает номер версии, проверяет package name,
путь загрузки и SHA-256 APK. После загрузки кнопка открывает системный установщик.
Установщик Android проверяет подпись приложения и просит подтвердить установку.
Телефон и компьютер для самой проверки/установки не соединяются кабелем.

Новая версия публикуется тегом `android-vX.Y.Z` в репозитории
`zelimhan2332/bumbari-preview`. Workflow собирает release APK, создаёт manifest
с контрольной суммой и публикует оба файла. Обновляющий APK должен иметь тот же
application ID `ru.bumbari.patterns` и быть подписан тем же ключом, иначе Android
откажется обновлять приложение поверх установленной версии.

## Однократная настройка подписи выпуска

Владелец создаёт отдельный ключ выпуска и хранит резервную копию отдельно от
репозитория. Например, локально выполнить `keytool -genkeypair -v -keystore
bumbari-release.jks -alias bumbari-upload -keyalg RSA -keysize 4096 -validity
10000`. Не отправлять `.jks` и пароли в GitHub как обычные файлы или сообщения.

В настройках репозитория открыть **Settings → Secrets and variables → Actions**
и добавить секреты:

- `ANDROID_KEYSTORE_BASE64` — содержимое JKS, закодированное Base64;
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
- `ANDROID_KEY_ALIAS` — `bumbari-upload` (или выбранный alias);
- `ANDROID_KEY_PASSWORD` — пароль ключа.

После настройки создать тег выпуска на актуальном коммите, например
`android-v0.3.0`. GitHub Actions проверит тесты, соберёт APK и приложит к выпуску
`bumbari-android-release.apk` и `update.json`.
Код версии выпуска формируется как `1000 + номер запуска workflow`, поэтому он
выше установленной отладочной версии и растёт с каждым выпуском.

## Переход с установленной debug-сборки

Телефон сейчас использует debug APK, подписанный локальным отладочным ключом.
Release APK с новым ключом нельзя установить поверх debug APK. Для перехода
потребуется один раз заменить установку release-подписанной сборкой. Перед этим
сохранить все нужные файлы проектов через экспорт JSON и убедиться, что они
открываются. Удаление приложения очищает его внутренний список проектов.
После перехода новые версии можно получать из приложения без кабеля.

На Android 8 и выше при первой установке из Bumbari система может попросить
разрешить установку приложений из этого источника. Установка остаётся явной:
Android показывает своё окно подтверждения. Приложение не может устанавливать
APK скрытно.

Пока нет GitHub Release с APK и секретов подписи, проверка обновления из приложения
вернёт сообщение, что опубликованного выпуска нет. Это намеренное состояние до
настройки первого подписанного выпуска.
