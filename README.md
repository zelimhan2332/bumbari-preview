# Bumbari — публичная тестовая версия

Постоянная ссылка: https://zelimhan2332.github.io/bumbari-preview/

## Где что находится

Это репозиторий **рабочего браузерного приложения**. Для опубликованной версии используется ветка `test`; исходники сайта находятся в `preview/`. Изменения делаются отдельной веткой и PR в `test`, затем GitHub Actions запускает проверки и публикацию.

Репозиторий [`zelimhan2332/mueller`](https://github.com/zelimhan2332/mueller) хранит требования, методику и навык работы с источниками. Его папка `preview/` — отдельная устаревшая копия и не является источником этого сайта. Репозитории не синхронизируются автоматически. Не переносить старый `mueller/preview` поверх этого приложения; изменения между репозиториями переносить только точечно, после проверки и через PR.

Полный порядок реализации и статусы разделов: [IMPLEMENTATION.md](IMPLEMENTATION.md).
Результаты сверки первой основы с изображениями книги: [BOOK-REVIEW.md](BOOK-REVIEW.md).

Учебный браузерный прототип: прямая юбка, манекен, проекты, PDF 1:1.
Источник кроя: «Ателье. М. Мюллер и сын. Техника кроя», 2001, PDF 5–7.
Книги, личные мерки и секреты сюда не загружаются. Лицензии сторонних
ресурсов сохранены в preview/assets.

## Обновления

Рабочие изменения оформляются отдельной веткой и PR в ветку `test`.
После слияния GitHub Actions запускает все тесты и автоматически публикует
браузерные файлы. Прямых коммитов в main не требуется. Основной закрытый
репозиторий не синхронизируется автоматически: переносить только проверенные
файлы preview, отдельным PR. Секрет доступа к закрытому репозиторию не нужен.
Ссылка не меняется; публикация обычно занимает несколько минут, не мгновенна.
Открытая вкладка проверяет обновление страницы и перезагружается.

## Ограничения и проверки

Два числовых примера книги не подтверждают всю геометрию. Для остальных мерок
распределение вытачек экспериментальное. Контуры без припусков, обязательны
сверка с книгой, контрольный квадрат 100 мм и примерка макета. Не использовать
как проверенную производственную выкройку. Другие изделия запланированы.

Локально открыть preview/index.html. Все preview/*.test.js запускать Node 24.
Исходная версия: закрытый mueller PR #10, aac9a10. Для Pages исправлена
проверка обновлений: относительный index.html вместо корня домена.
