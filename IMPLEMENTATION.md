# Поэтапная реализация Bumbari по книге

Общее поручение владельца: реализовать программу по книге, продолжать без
повторного согласования каждого уже утверждённого этапа. Этот список —
инженерная последовательность, не заявление о готовности всей книги.

Источник: «Ателье — 2001», 168 PDF-страниц. Номера ниже — PDF, не печатные.

## Обязательная проверка каждой конструкции

1. Визуально прочитать страницы и рисунки, записать единицы и обозначения.
2. Разделить мерки человека, расчётные величины, прибавки и припуски.
3. Реализовать независимый числовой контроль примера источника.
4. Реализовать точки/линии; проверить вытачки, длины, сопряжения и применимость.
5. Показать статус в интерфейсе; неподтверждённое не называть готовым лекалом.
6. Проверить PDF 1:1, A4/A0, квадрат 100 мм, долевую и маркировку деталей.
7. Проверить браузерный сценарий и сохранить отчёт; физическая примерка отдельно.
8. Ветка → PR → тесты → публикация на постоянной тестовой ссылке.

## Общие незавершённые пункты

- Проверка и настройка баланса по фигуре, а не обещание посадки по обхватам.
- Прямая юбка без подкладки: пояс по PDF9, припуски/молния/шлица по PDF16.
  Инженерные кривые, капы вытачек и соединения припусков требуют бумажной
  проверки и примерки. См. docs/SKIRT-KIT-REVIEW.md.
- Понятное разделение экспериментального и подтверждённого режима.
- Браузерные проверки, реальная печать и макет для каждой конструкции.
- Полный комплект брюк, проверка сопряжения швов, припусков и посадки на макете.
- Манекен остаётся скрытым по просьбе владельца.

если в выбранном сборнике нужного варианта нет, нужен отдельный источник.
