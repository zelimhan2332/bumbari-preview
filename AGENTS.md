# Правила проекта Bumbari

- Единый исходный репозиторий — `zelimhan2332/bumbari-preview`; приложение — `preview/`, знания и документация — `docs/` и `skills/`.
- Тестовая публикация берётся из ветки `test`: https://zelimhan2332.github.io/bumbari-preview/ . Не меняй название репозитория или настройки публикации без отдельного поручения.
- Перед работой проверь `git fetch origin`, активную ветку и чистоту дерева. Работай отдельной веткой; открывай PR в `test`, не коммить напрямую в `test`.
- Перед изменением построения открой нужный раздел книги и визуально сверь формулы/чертёж; фиксируй издание, страницы, единицы и контрольный пример.
- Разделяй цитируемые правила источника, собственные конспекты и инженерные решения. Не выдавай экспериментальную геометрию за проверенную по книге.
- Не добавляй PDF, полный OCR, личные мерки, клиентские фото, секреты, ключи подписи и локальные абсолютные пути владельца.
- Не удаляй пользовательские данные без ясного поручения. Не изменяй проекты Уммы и их серверы.
- Проверяй изменения относящимися тестами и `git diff --check`. Для PDF дополнительно нужна реальная печать 100% с контролем квадрата 100 × 100 мм и макет.
